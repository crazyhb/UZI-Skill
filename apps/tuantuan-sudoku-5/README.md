# 团团数独 · 5×5 拼图版

给「团团」准备的 **5×5** 数独，最适合第一次玩数独的小朋友。手机和电脑都能玩。

5 是质数，切不出整齐的小方格，所以"宫"是 **5 块形状各异的彩色拼图**，每块 5 格。规则一句话：同一行、同一列、同一块拼图里，图案都不能重复。

## 在手机上玩

- 固定地址（需要先开 GitHub Pages，见 `../tuantuan-sudoku/README.md`）：<https://crazyhb.github.io/UZI-Skill/tuantuan-sudoku-5/>
- 三款游戏的入口页：<https://crazyhb.github.io/UZI-Skill/>

加到手机桌面后可以全屏、离线玩：iPhone 在 Safari 点「分享 → 添加到主屏幕」；安卓在 Chrome 点「⋮ → 添加到主屏幕」。

## 在电脑上玩

```bash
python3 -m http.server 8765 -d apps
# 访问 http://localhost:8765/tuantuan-sudoku-5/
```

## 难度

| 模式 | 空格 | 适合谁 |
|---|---|---|
| 启蒙 5×5 | 5 格 | 每块拼图正好缺一个，找"少了谁" |
| 轻松 5×5 | 9 格 | 会看行、列和拼图块了 |
| 聪明 5×5 | 最多 13 格 | 团团自己想一想 |

格子可以换成水果、小动物或数字（1–5）。格子很大，小手指好点。点空格再点下方图案；不能放的图案会变淡。提供擦掉、提示、检查。

## 题目怎么来的

盘面很小，布局和解都在页面里现场生成：随机把 5 行拼图块的边界格子互换、保持连通，用回溯法填出一个完整解，再逐格挖空并校验唯一解。每次出题约 1ms。

```bash
node apps/tuantuan-sudoku-5/tests/sudoku5.test.cjs
```
